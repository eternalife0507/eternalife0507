## 🚧 What I'm building

### SAiFETY Talk
A mobile-first safety reporting app for construction and shipyard field workers.

**The problem:** Incident reporting is high-friction. Workers skip it, and near-misses go unrecorded.

**The approach:** Photo → AI-generated report draft in ~5 seconds → quick edit → submit. Inspired by the photo-to-listing flow in Korean marketplace apps.

| | |
|---|---|
| **Stack** | React · TypeScript · TanStack · Supabase (Postgres, Storage, Auth) |
| **AI** | Multimodal LLM for photo classification and draft generation |
| **Domains** | Construction and shipyard, independently deployable via feature flags |
| **Status** | Pilot preparation |

## 💭 How I work

- **Investigate before building.** I check the actual schema and codebase before writing a line — assumptions about what exists have burned me enough times.
- **Design for the worst conditions.** Gloved hands, bright sun, spotty signal, no patience. If it doesn't work there, it doesn't work.
- **Keep blast radius small.** Feature flags, isolated domains, reversible changes.
